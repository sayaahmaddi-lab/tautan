TAUTAN — APLIKASI KOLEKSI TAUTAN

CARA MEMBUKA
Buka alamat deployment aplikasi melalui browser, atau jalankan server sesuai
petunjuk di README.md. Aplikasi harus diakses melalui server; membuka
index.html langsung dari file tidak memuat koleksi.

CARA MENGGUNAKAN
- Klik Tambah tautan untuk menyimpan alamat website.
- Klik bintang untuk menandai favorit.
- Klik tombol tiga titik pada kartu untuk mengedit atau menghapus.
- Gunakan pencarian dan kategori untuk menemukan tautan.

PENYIMPANAN
Semua data koleksi dimuat dari dan disimpan ke database Neon melalui API
/api/links. Aplikasi tidak menggunakan localStorage atau penyimpanan file.
NEON_DATABASE_URL harus tersedia pada server lokal maupun konfigurasi Vercel.
Jika database tidak tersedia, aplikasi tidak dapat memuat atau menyimpan tautan.

INTERNET
Koneksi internet diperlukan untuk mengakses aplikasi, database, dan website
tujuan yang tersimpan.
