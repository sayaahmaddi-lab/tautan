TAUTAN — VERSI KOMPUTER PRIBADI

CARA MEMBUKA
1. Ekstrak seluruh isi ZIP ini (klik kanan > Extract All / Ekstrak Semua).
2. Buka folder hasil ekstrak.
3. Klik dua kali index.html. Halaman akan terbuka di browser.
   Jika perlu, klik kanan > Buka dengan > Google Chrome / Microsoft Edge / Firefox.

Tidak memerlukan GitHub, Node.js, atau server.
Jangan membuka HTML langsung dari dalam ZIP.
Simpan index.html, links.css, dan links.js di folder yang sama.
Anda boleh membuat shortcut index.html di Desktop.

CARA MENGGUNAKAN
- Klik Tambah tautan untuk menyimpan alamat website.
- Klik bintang untuk menandai favorit.
- Klik di mana saja pada kartu untuk membuka tautan tersebut.
- Klik tombol tiga titik pada kartu untuk mengedit atau menghapus.
- Gunakan pencarian dan kategori untuk menemukan tautan.

PENYIMPANAN
Ada dua mode penyimpanan. Status mode yang sedang aktif terlihat di kiri bawah halaman.

1. MODE DATABASE NEON (disarankan — semua perubahan tersimpan)
   - Pasang Node.js 18+, lalu jalankan: npm install dan npm start.
   - Sambungkan database Neon: salin .env.example menjadi .env, lalu isi
     DATABASE_URL dengan connection string dari proyek Neon Anda.
   - Buka halaman melalui server (misalnya http://localhost:3000).
   - Semua penambahan, pengubahan, dan penghapusan langsung tersimpan di database.
   - Tanpa DATABASE_URL, server menyimpan data di data/links.json.
   - Saat pertama tersambung, koleksi yang ada di browser otomatis disalin ke database.

2. MODE BROWSER (tanpa server, seperti versi sebelumnya)
   - Buka index.html langsung di browser.
   - Koleksi disimpan di penyimpanan lokal browser (localStorage).
   - Mode privat, penghapusan data browser, atau pemindahan file dapat
     menyebabkan koleksi tidak tersimpan atau tidak terlihat.

INTERNET
Halaman koleksi dapat dibuka tanpa internet. Font menggunakan font cadangan
saat offline. Internet tetap dibutuhkan untuk membuka website tujuan.
Versi ini memakai tautan portal SIPD resmi, bukan dashboard API SIPD server.
