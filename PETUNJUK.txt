TAUTAN — VERSI DATABASE NEON

CARA MEMBUKA
Aplikasi ini hanya bekerja lewat server/aplikasi web yang terhubung ke database
Neon. Buka alamatnya di browser (contoh: https://tautan-rho.vercel.app).
Membuka index.html langsung dari folder (klik dua kali) TIDAK lagi menampilkan
atau menyimpan koleksi, karena tidak ada penyimpanan di browser.

CARA MENGGUNAKAN
- Klik Tambah tautan untuk menyimpan alamat website.
- Klik bintang untuk menandai favorit.
- Klik tombol tiga titik pada kartu untuk mengedit atau menghapus.
- Gunakan pencarian dan kategori untuk menemukan tautan.

PENYIMPANAN
Database Neon (Postgres) adalah SATU-SATUNYA penyimpanan.
Semua perubahan — tambah, edit, favorit, dan hapus — langsung dikirim ke
database Neon melalui API /api/links. Halaman hanya membaca data dari API
tersebut; tidak ada data yang ditulis ke localStorage/sessionStorage browser.
Tautan jadi sama di semua perangkat dan browser.

Status di sidebar menunjukkan keadaan penyimpanan:
- "Memuat dari database Neon…"  → halaman sedang mengambil data.
- "Tersimpan di database Neon"  → semua perubahan masuk ke database Neon.
- "Database Neon tidak terhubung" → data tidak dapat dimuat; periksa
  NEON_DATABASE_URL pada environment server/Vercel, lalu muat ulang halaman.
  Selama itu koleksi dibiarkan kosong — tidak ada data contoh dan tidak ada
  penyimpanan di browser.

INTERNET
Internet dibutuhkan untuk memuat dan menyimpan koleksi (database Neon) serta
untuk membuka website tujuan.
